04 / EXECUTION

Same ledger. Different ownership.

The tiny constructor illustrates which layer turns a Compact Cell write into ledger VM instructions.

ORACLE GENERATED CODEExplicit VM program
let ops = OpProgramVerify::new()
    .push(false, new_cell(0u8))
    .push(true, new_cell(value))
    .ins(false, 1)
    .build();

let result = query_for_verify(&qctx, &ops, ...)?;

Generated functions choose the VM stack operations and assemble a program. The runtime supplies builders, Cell constructors, and the query helper.

LOCAL GENERATED CODETyped context calls
let step = context.write_cell(0, authority)?;
context = step.context;
let step = context.write_cell(1, value)?;
context = step.context;

Ok(context.into_constructor_result())

Generated functions name a typed Cell action and pass along the updated context. The runtime encodes the value, constructs the VM operations, and runs the query.

FOLLOW ONE WRITE

Who knows the VM stack?

Both end at the ledger-8 QueryContext::query. The boundary between generated code and runtime moves.

Generated Rust

Oracle selects Push/Ins and builds an OpProgramVerify.

Local selects write_cell, the field path, and the typed value.

Runtime

Oracle offers builders, value constructors, and a thin query wrapper.

Local handles CellValue encoding, builds the Op array, and calls the ledger query.

Query granularity

Oracle batches the three tiny constructor writes into one VM program and query.

Local makes three write_cell calls; each queries and returns an updated context.

Consequence. Moving op construction into the runtime gives the compiler a smaller, typed vocabulary and one place to fix Cell behavior. It also makes the runtime adapter more substantial. Final-state behavior has parity tests; identical gas costs and VM transcripts for these two query shapes have not been established.

Shared foundationBoth delegate actual state transitions to the ledger-8 on-chain VM and reuse upstream FAB, field, and curve implementations.
Macro modelThe oracle provides a #[witnesses] forwarding attribute. The local renderer derives upstream field and hash representations plus local Cell and Merkle codecs; witnesses remain an explicit generated trait.
Generated APIThe oracle emits a Contract<PS, W> with methods and a crate manifest. The local output exposes free functions with explicit contexts and witnesses; consumers currently supply the manifest.

06 / ASSESSMENT

Keep the architecture. Close the product gap.

The typed model is a stronger maintenance boundary; the oracle still provides a smoother generated-crate experience.

01

Architectural gain

Scheme exports a versioned Compact model. Rust validates it, constructs syntax nodes, and preserves bounds in API types. New shapes require deliberate variants rather than text interpolation.

02

Integration debt

The local wrapper is a second process, still produces TS side output, and leaves Cargo.toml to consumers. Renderer errors need original Compact source spans; release metadata is still local.

03

Next gates

Make Rust a first-class compiler target, emit a manifest, carry source spans through IR, expand the negative/acceptance matrix, and add focused gas and transcript parity tests.
